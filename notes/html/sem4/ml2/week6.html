Constrained Optimization, Lagrange Multipliers and KKT Conditions

Machine Learning 2 — Week 6

Imagine a hiker who wants to reach the lowest point of a valley. Without any restrictions, the answer is easy: keep walking downhill until the ground is flat. Now someone builds fences across the valley, and the lowest reachable point may sit right against a fence, on a slope that is still tilted downhill. Everything in this chapter is about finding that point reliably, and the Support Vector Machine is exactly such a hiker with fences.

1. The SVM Story So Far

We are given a dataset of n labelled points

D={(x1​,y1​),…,(xn​,yn​)},yi​∈{−1,+1}

where yi​=−1 marks one class and yi​=+1 marks the other. The task is a binary classification problem: find a linear boundary that separates the two classes and maximizes the margin between them. Many lines may separate the classes, but only one of them leaves the widest empty "road" between the two groups.

Geometry of the hard-margin SVM

  • θ is the normal vector of the boundary.
  • b is the offset (bias) of the boundary from the origin. The actual distance of the boundary from the origin is ∣b∣/∥θ∥.
  • The boundary itself is x⊤θ+b=0.
  • The two margin hyperplanes are x⊤θ+b=+1 and x⊤θ+b=−1.
  • The points lying exactly on the margin hyperplanes are the support vectors.

Why does maximizing the margin equal minimizing θ⊤θ? The distance of a point x0​ from the boundary is ∥θ∥∣x0⊤​θ+b∣​. A point on x⊤θ+b=1 is therefore at distance γ=∥θ∥1​, and the total margin width is

2γ=∥θ∥2​

Making 2γ large is the same as making ∥θ∥ small, which is the same as making θ⊤θ small.

Hard-margin SVM (linearly separable classes)

θ,bmin​θ⊤θs.t.yi​(θ⊤xi​+b)≥1,i∈{1,…,n}

The constraints make sure that all data points are correctly classified: every positive point (yi​=+1) lies beyond the +1 line and every negative point (yi​=−1) lies beyond the −1 line. Multiplying by yi​ merges both statements into one inequality.

Reading the figure: the solid blue line is the decision boundary, the two dashed lines are the margin hyperplanes x⊤θ+b=±1, and the distance between the dashed lines is 2γ. The two circled points (one per class) sit exactly on the dashed lines. They are the support vectors, and they alone determine the position of the boundary.

SVM for non-separable classes (soft margin)

Sometimes no line separates the two classes perfectly, because a few red points land on the green side and a few green points land on the red side. If this happens for only a very small fraction of the data, we can still use a linear boundary and treat the offending points as outliers.

To allow this, each data point xi​ gets a slack variable ηi​≥0, which is the amount by which that point is allowed to go beyond its margin hyperplane. If a point is on the correct side and outside the margin, ηi​=0.

But the slacks cannot be free: if we allowed large slack everywhere, any boundary would look "feasible". So the total slack is penalized in the cost, which keeps the amount of violation as small as possible.

θ,b,ηmin​θ⊤θ+ci=1∑n​ηi​s.t.yi​(θ⊤xi​+b)≥1−ηi​,i∈{1,…,n}ηi​≥0,i∈{1,…,n}

Here c is a hyperparameter: it sets the exchange rate between a wide margin (small θ⊤θ) and few margin violations (small ∑i​ηi​).

Hard margin Soft margin
Unknowns θ,b θ,b,η
Cost θ⊤θ θ⊤θ+c∑i​ηi​
Constraint yi​(θ⊤xi​+b)≥1 yi​(θ⊤xi​+b)≥1−ηi​, ηi​≥0
Works when Classes are linearly separable Always

Note for Review — The soft-margin problem is the more general one. If the classes are linearly separable, the optimizer simply returns all ηi​=0 and you recover the hard-margin SVM. A large c punishes violations heavily (closer to hard margin); a small c tolerates many violations in exchange for a wider margin.

2. Rewriting SVM as a Quadratic Program

Before choosing a solver, we put both SVM problems into one standard shape. The shape is: quadratic cost, linear inequality constraints.

2.1 Hard-margin SVM

Define the stacked variable ω=(θ,b). The cost θ⊤θ has no b in it, so we add a harmless term 0⋅b⊤b and write the cost as a quadratic form in ω:

θ⊤θ+0b⊤b=[θ⊤​b​][I0⊤​00​][θb​]=ω⊤Bω

Check by multiplying: first Bω=[Iθ+0⋅b0⊤θ+0⋅b​]=[θ0​], then ω⊤(Bω)=θ⊤θ+b⋅0=θ⊤θ.

Each constraint becomes a row-vector times ω:

yi​(xi⊤​θ+b)=yi​xi⊤​θ+yi​b=[yi​xi⊤​​yi​​][θb​]≥1

Stacking all n rows gives the matrix A, and the vector 1 is the vector of all ones:

A=⎣⎡​y1​x1⊤​y2​x2⊤​⋮yn​xn⊤​​y1​y2​⋮yn​​⎦⎤​,Aω≥1

So the hard-margin SVM is

ωmin​ω⊤Bωs.t.Aω≥1

2.2 Soft-margin SVM

Step 1 — Start from the problem:

θ,b,ηmin​θ⊤θ+0b⊤b+ci=1∑n​ηi​s.t.yi​(xi⊤​θ+b)≥1−ηi​∀i

Step 2 — Turn the sum into an inner product. The slack sum is

i=1∑n​ηi​=η1​+η2​+⋯+ηn​=1⋅η1​+1⋅η2​+⋯+1⋅ηn​=[1​⋯​1​]⎣⎡​η1​⋮ηn​​⎦⎤​=1⊤η

θ,b,ηmin​quadratic termsθ⊤Iθ+b⊤0b+η⊤0η​​+linear termsc1⊤η+0⊤θ+0⋅b​​

Step 5 — Stack everything into one vector. Let ω=(θ,b,η)∈Rd+1+n. The quadratic part is

[θ⊤​b⊤​η⊤​]⎣⎡​I00​000​000​⎦⎤​⎣⎡​θbη​⎦⎤​=ω⊤Qω

The block sizes are d, 1, n along each side. Multiplication check: Qω=⎣⎡​θ00​⎦⎤​, hence ω⊤Qω=θ⊤θ.

The linear part is

r⊤ω=[0⊤​0​c1⊤​]⎣⎡​θbη​⎦⎤​=0⊤θ+0⋅b+c1⊤η=ci=1∑n​ηi​

Note for Review — The order of the blocks in r must match the order in ω. Since ω=(θ,b,η), the nonzero block c1⊤ must sit in the η position (last). Writing it first by accident would penalize θ instead of the slacks.

Step 6 — Stack the constraints. For data point i, the row of A is [yi​xi⊤​​yi​​ei⊤​​], where ei​∈Rn has a 1 in position i and 0 elsewhere, so that it picks out exactly ηi​:

[yi​xi⊤​​yi​​ei⊤​​]⎣⎡​θbη​⎦⎤​=yi​xi⊤​θ+yi​b+ηi​≥1

All n rows together:

A=⎣⎡​y1​x1⊤​y2​x2⊤​⋮yn​xn⊤​​y1​y2​⋮yn​​10⋮0​010​⋯⋯⋱⋯​00⋮1​⎦⎤​=[diag(y)X​y​In​​]

where X∈Rn×d has the data points xi⊤​ as rows.

Step 7 — The final quadratic program:

ωmin​ω⊤Qω+r⊤ωs.t.Aω≥1

The cost is quadratic and the constraints are linear inequalities, so this is a Quadratic Program (QP) with linear inequality constraints. Compared with the hard-margin version, the only new ingredient is the linear term r⊤ω, which exists because of the slack variables introduced to handle outliers.

Note for Review — The slack constraints ηi​≥0 are also linear inequalities. To be fully complete, append the rows [0​0​In​​]ω≥0 below Aω≥1. This is why the soft-margin SVM has 2n inequality constraints in total (n margin constraints and n non-negativity constraints), while the hard-margin SVM has n.

1. Soft-Margin SVM

Starts with the original SVM optimization problem. The model minimizes the squared norm of the weight vector, θTθ, plus a penalty for violations represented by the slack variables ηi​.

2. Pad with Zero Blocks

The variables are reorganized into one larger optimization vector ω. The bias b and slack variables η do not contribute to the quadratic part, so their corresponding blocks in the quadratic matrix are zero blocks.

3. Collect the Slack Sum

The summation of slack variables is rewritten as a vector dot product:

i∑​ηi​=1Tη

This allows the SVM objective to be expressed as a standard quadratic term plus a linear term.

4. Stack the Constraints

Each individual SVM constraint:

yi​(θTxi​+b)+ηi​≥1

is converted into one row of a matrix:

[yi​xiT​​yi​​eiT​​]ω≥1

Stacking the constraints for every training example gives:

Aω≥1

5. Quadratic Program

The final result is the standard QP form:

ωmin​21​ωTQω+rTωsubject to: Aω≥1

Summary Pipeline:

Original Soft-Margin SVM → Block-Matrix Reformulation → Linear-Term Collection → Constraint Matrix → Standard QP Formulation

The next question is how to solve such problems. For that we need the theory of constrained optimization, starting with the simplest case.

3. Why Setting the Gradient to Zero Fails

Without constraints, minimizing a function is simple: differentiate, set the gradient to zero, solve. Let us see what constraints do to this recipe with the simplest possible function, f(x)=x2.

Unconstrained: minx∈R​f(x). Here f′(x)=2x=0 gives x∗=0. Since x may be any real number, this is the answer.

Case 1 — subject to x=2. Only one point is feasible, so the optimal solution is trivially x∗=2.

Case 2 — subject to x≥2. Now x may only live in [2,∞). On this range f keeps increasing as x grows, so the smallest value is at the left edge: x∗=2.

The red segment is the feasible set x≥2 (the shaded region on the lecture slide). The optimum is at x∗=2, but

∇f(x)∣∣​x=2​=2x∣∣​x=2​=4=0

So at a constrained optimum the gradient of f does not have to vanish. Our old idea "set ∇f=0" no longer gives the answer. We need a new condition, and the Lagrange multiplier technique supplies it.

4. Equality Constrained Optimization

The general equality-constrained problem is

xmin​f(x)subject tog1​(x)=0,g2​(x)=0,…,gk​(x)=0

with f:Rn→R and each gi​:Rn→R. In words: f and the gi​ are multivariable functions that return a single number, and x∈Rn is an n-dimensional vector that must satisfy all k constraints while minimizing f.

Note for Review — The slide indexes the constraints up to m. In these notes the number of equality constraints is k and the number of inequality constraints is m (introduced in Section 8), so that the two letters never clash.

5. The Geometry Behind Lagrange Multipliers

We derive the key condition with a single constraint g(x)=0, step by step.

Step 1 — The feasible set. Let S={x∣g(x)=0} be the set of all points that satisfy the constraint (the feasible set). For n=2, g(x)=0 describes a curve. For example:

  • g(x)=x12​+x22​−1=0 is a circle.
  • g(x)=x1​+x2​−1=0 is a line.

Step 2 — Two nearby feasible points. Take x∈S and another point y∈S very close to it, so that y=x+Δx with Δx tiny. Locally the curve looks flat, and Δx is a vector pointing along the curve (tangent direction). Because both points are feasible:

g(x)=g(y)=0

Step 3 — Taylor expansion of g around x.

g(y)=g(x+Δx)=g(x)+∇g(x)⊤Δx+O(∥Δx∥22​)

Since Δx is very small, the higher-order term is negligible. Using g(y)=g(x)=0:

∇g(x)⊤Δx=0

Step 4 — Meaning. The inner product of ∇g and Δx is zero, so ∇g is perpendicular to the tangent direction Δx. In other words, at every point, ∇g is perpendicular (normal) to the constraint curve.

Step 5 — What optimality demands of f. Suppose x is an optimal solution and compare f(x) with f(x+Δx), where x+Δx is another feasible point. To first order,

f(x+Δx)≈f(x)+∇f(x)⊤Δx
  • If ∇f(x)⊤Δx<0, then f(x)>f(x+Δx): we found a feasible point with a smaller value, so x was not optimal.
  • If ∇f(x)⊤Δx>0, then the opposite direction −Δx is also feasible (to first order) and decreases f. Again x was not optimal.

So at an optimum, the rate of change of f along the constraint curve must be zero: ∇f(x∗)⊤Δx=0. Therefore ∇f is also perpendicular to the tangent direction. Both ∇f and ∇g are perpendicular to the same tangent line, so they are parallel (their magnitudes may differ, hence a scalar λ):

∇f(x∗)=λ∇g(x∗)

Note for Review — With several constraints, the same argument shows that ∇f(x∗) must be a linear combination of ∇g1​(x∗),…,∇gk​(x∗), one multiplier per constraint.

Picture: suboptimal vs optimal point

The contours of f are circles centered at the unconstrained minimum ⋆ (here at the origin), and the constraint is the straight line g(x)=x1​+x2​−2=0. At x=(2,0) we can slide along the line toward the center and decrease f. The sliding stops exactly where the line touches a contour: that point q=(1,1) is the constrained optimum, and there ∇f∥∇g.

Legend: gray and orange circles are the contours f(x)=c; the dashed blue line is g(x)=0; the orange contour is the one the line just touches.

6. The Lagrangian Recipe

The condition ∇f=λ∇g together with g(x)=0 can be produced mechanically. Define the Lagrange function (Lagrangian)

L(x,λ)=f(x)−λg(x)

The term λg(x) is a penalty term attached to the constraint, and λ is the Lagrange multiplier. Take the gradient with respect to each argument:

∇x​L=∇f(x)−λ∇g(x)=0⟹∇f=λ∇g∇λ​L=−g(x)=0⟹g(x∗)=0

The first equation is exactly the parallel-gradients condition we derived geometrically. The second is simply the original constraint. So we do not set ∇f=0 (we saw this fails). We solve the two equations together, for the two unknowns x and λ.

The given optimization process using Lagrange Multipliers can be represented in Markdown as follows:

Optimization via Lagrange Multipliers

1. Problem Formulation

Given:

  • Objective: minf(x)

  • Subject to: g(x)=0

2. Lagrangian Function

Construct the Lagrangian equation:

L(x,λ)=f(x)−λg(x)

3. Necessary Conditions (Stationary Points)

Differentiate the Lagrangian to set up the system of equations:

  • Gradient Condition (with respect to x):

    ∇f(x)=λ∇g(x)

  • Constraint Condition (with respect to λ):

    g(x)=0

4. Solve System of Equations

Solve the system consisting of n+k equations and n+k unknowns to determine candidate critical points.

5. Candidate Evaluation

Evaluate and compare f(x) at each candidate point to determine whether it corresponds to a minimum, maximum, or saddle point.

7. Worked Example on the Unit Circle

Problem. Minimize f(x1​,x2​)=x1​+x2​ subject to g(x1​,x2​)=x12​+x22​−1=0.

Step 1 — Lagrangian.

L(x1​,x2​,λ)=x1​+x2​−λ(x12​+x22​−1)

Step 2 — Three equations.

∂x1​∂L​=1−2λx1​=0(1)∂x2​∂L​=1−2λx2​=0(2)∂λ∂L​=−(x12​+x22​−1)=0⟹x12​+x22​−1=0(3)

Three equations, three unknowns (x1​,x2​,λ).

Step 3 — Solve.

  • From (1): λ=0 (otherwise 1=0), so x1​=2λ1​.
  • From (2): x2​=2λ1​. Hence x1​=x2​.
  • Substitute into (3):
(2λ1​)2+(2λ1​)2=1⟹4λ22​=1⟹λ2=21​⟹λ=±2​1​
  • For λ=+2​1​: x1​=x2​=2/2​1​=22​​.
  • For λ=−2​1​: x1​=x2​=−22​​.
Candidate λ x1​=x2​ f=x1​+x2​

The solution quoted for this example is λ∗=+2​1​, x1∗​=x2∗​=22​​, which is candidate A.

Note for Review — The Lagrange equations only produce critical points: they cannot tell a minimum from a maximum. Here both candidates satisfy all three equations. Candidate A (f=+2​) is the largest value of x1​+x2​ on the circle, while candidate B (f=−2​) is the smallest. So for the minimization problem as stated, the winner after comparing f values is B; A is the answer to the corresponding maximization. Pro-Tip: always evaluate f at every candidate and compare.

8. General Constrained Optimization

SVM has inequality constraints, so equality constraints alone are not enough. Here is the general setting:

f:Rn→R,g:Rn→Rk,h:Rn→Rm,x∈Rnx∈Rnmin​f(x)s.t.g(x)=0,h(x)≥0
  • g(x)=⎣⎡​g1​(x1​,…,xn​)⋮gk​(x1​,…,xn​)​⎦⎤​ stacks the k equality constraints, and 0 is a zero vector of size k×1.
  • h(x)≥0 stacks the m inequality constraints, each of the form hj​(x)≥0, and the 0 here has size m×1.
  • In the SVM, m=n for the hard-margin problem (one inequality per data point).

Equality constraints are handled exactly as before: one penalty term λi​gi​(x) per constraint. With the same idea for inequalities, using multipliers μj​:

L(x,λ,μ)=f(x)−λ1​g1​(x)−⋯−λk​gk​(x)−μ1​h1​(x)−⋯−μm​hm​(x)=f(x)−λ⊤g(x)−μ⊤h(x)

Its gradient with respect to x is

∇L=∇f−λ⊤∇g−μ⊤∇h(x)=∇f−i=1∑k​λi​∇gi​−j=1∑m​μj​∇hj​=0

(here ∇g and ∇h denote the Jacobian matrices, whose rows are the gradients of the individual constraint functions).

The question: can we simply set this gradient to zero and solve for x? For equality constraints, yes. But with inequalities not directly: some inequality constraints will matter for the answer and some will not, and the equation above treats all of them as if they mattered. To fix that, we must understand when an inequality constraint is active.

Note for Review — The recipe for solving depends on the type of problem. If f is quadratic and the constraints are linear (a QP, as in the SVM), specialized and efficient algorithms exist. If f is non-convex and the constraints are highly non-linear, the gradient equations are much harder to solve and need different algorithms. These solvers come later; for now the focus is on the conditions an optimal point must satisfy.

9. Active vs Inactive Constraints

Consider one inequality constraint h(x)≥0.

  • h(x)=0 is a curve (the boundary).
  • h(x)>0 is the whole region on one side of the curve.
  • The feasible set is the set of all x satisfying the inequality constraints.

There are exactly two situations, depending on where the unconstrained optimum of f lies.

Reading the figure: the shaded half-plane is the feasible set h(x)>0, its edge is h(x)=0, and the gray circles are contours of f. The hollow circle on the left panel is the unconstrained minimum, which lies outside the feasible set. (Style after Solomon, 2015.)

Case A — Active constraint: the global optimum is not feasible

The unconstrained optimum is cut off by the constraint. The best feasible point must then lie on the boundary h(x)=0. The constraint is active and the problem behaves like the equality-constrained problem h(x)=0. All points strictly inside the region are irrelevant.

Example (from the 1D function): minimize x2 subject to x≥2. The global minimizer x=0 is infeasible, so x∗=2, on the boundary.

Case B — Inactive constraint: the global optimum is feasible

The unconstrained optimum already satisfies the constraint with room to spare, so the fence changes nothing. The constraint is inactive and can be ignored entirely: just solve ∇f=0.

Example: minimize x2 subject to x≥−2. The global minimizer x=0 satisfies x≥−2, so x∗=0 (and ∇f(0)=0, as in the unconstrained case).

Is the unconstrained optimum feasible? No Yes
Where is x∗? On the boundary: h(x∗)=0 In the interior: h(x∗)>0
How to treat it As an equality constraint Ignore it

The mountain analogy

Picture the hiker from the start of this chapter heading for the lowest point of a valley. If the fences are far away (or not there at all), the hiker reaches the true bottom, and the fences never mattered: they are inactive. If there is a fence, say around a volcano, that stops the hiker before the bottom, the hiker ends up standing against the fence: that fence is active, and the hiker's position is determined by it. Active fences behave like equality constraints (you are on them); inactive ones can be removed without changing the answer.

The inequality constraint decision process can be represented in Markdown as follows:

Inequality Constraint Optimization (KKT Framework)

1. Problem Setup

  • Constraint: h(x)≥0

2. Feasibility Check

Determine whether the unconstrained optimum of f(x) satisfies h(x)≥0.

  • If YES → Inactive Constraint

    • Condition: h(x∗)>0

    • Multiplier: μ=0

    • Action: Ignore the constraint boundary (the fence does not bind).

  • If NO → Active Constraint

    • Condition: h(x∗)=0

    • Multiplier: μ≥0

    • Action: Treat as an equality constraint along the boundary.

Note for Review — The trouble: we never know in advance which constraints are active, because that would require already knowing where the global optimum is, and if we knew that we would not need to solve anything. The next two sections build a rule that works without knowing the answer beforehand.

10. Complementary Slackness

Back to the gradient equation

∇f−i=1∑k​λi​∇gi​−j=1∑m​μj​∇hj​=0

It includes a term for every inequality constraint. But inactive constraints must not take part in this equation, because they do not influence the optimum.

Small example. Let k=1 and m=2, where constraint h2​ is active and constraint h1​ is inactive. The correct equation is

∇f−λ1​∇g1​−μ2​∇h2​=0

and the term μ1​∇h1​ must be absent. The same effect is obtained by keeping the term but forcing its multiplier to zero: μ1​=0.

So for each inequality constraint:

μj​={0≥0​for inactive constraints (hj​>0)for active constraints (hj​=0)​

(for an active constraint the multiplier is normally strictly positive; the degenerate case μj​=0 with hj​=0 is also allowed, which is why the final conditions say μj​≥0).

One equation covers both cases. Because we cannot tell beforehand which case holds, we use the fact that in every case one of the two factors vanishes:

  • inactive: μj​=0,
  • active: hj​=0.

Hence the product is always zero:

μj​hj​(x∗)=0,j=1,…,m

This is the complementary slackness condition. With it, all terms can stay in the gradient equation, and the inactive ones switch themselves off.

Situation hj​(x∗) μj​ Product μj​hj​
Inactive >0 0 0
Active 0 ≥0 0

11. The Sign of the Multiplier

There is one more piece of information hidden in an active constraint: the direction in which the constraint pushes.

For an active constraint the optimum lies on the boundary, and as in the equality case the gradients are parallel:

∇f=μ∇h

The magnitude can differ (so we keep a scalar μ), but now the direction also matters:

μ≥0​for constraints of the form h(x)≥0

Why? The gradient ∇h points toward the region where h is larger, which is the feasible side. At a boundary optimum, the function f must increase as we move into the feasible region (otherwise we would walk inside and find lower values). So ∇f points into the feasible region too, in the same direction as ∇h, hence μ≥0. If ∇f pointed the opposite way (μ<0), then −∇f would point into the feasible region, and we could step inside and decrease f while still satisfying the constraint, which contradicts optimality.

Sketch: a family of elliptical contours of f with its center outside the feasible region, and ∇f pointing from the boundary into the feasible region.

Note for Review — The sign depends on how the constraint is written. For h(x)≥0 we need μ≥0. If a constraint is written as h(x)≤0, then ∇f must point opposite to ∇h at the optimum, and so μ≤0. The easiest habit: always rewrite inequalities into the form h(x)≥0 before writing the Lagrangian. Multipliers λi​ of equality constraints have no sign restriction.

12. The KKT Conditions

Putting all the pieces together gives the Karush–Kuhn–Tucker (KKT) conditions.

Theorem 10.1 (KKT conditions). The vector x∗∈Rn is a critical point for minimizing f subject to g(x)=0 and h(x)≥0 when there exist λ and μ​ such that:

  1. Stationarity:
0=∇f(x∗)−i∑​λi​∇gi​(x∗)−j∑​μj​∇hj​(x∗)

  1. Primal feasibility: g(x∗)=0 and h(x∗)≥0

  2. Complementary slackness: μj​hj​(x∗)=0 for all j

  3. Dual feasibility: μj​≥0 for all j

(Source: Solomon, J., Numerical Algorithms: Methods for Computer Vision, Machine Learning, and Graphics, CRC Press, 2015. In the textbook the multiplier vectors are indexed by the sizes of g and h; here those sizes are k and m.)

Condition What it guarantees Where it came from
Stationarity No feasible descent direction: gradients balance Parallel gradients (∇f=λ∇g)
Primal feasibility The point obeys every constraint The problem statement itself
Complementary slackness Inactive constraints drop out of the equation μj​=0 if inactive, hj​=0 if active
Dual feasibility The fence pushes back the right way ∇f points into the feasible region

To find an optimal point of a constrained problem with equalities and inequalities, we solve these conditions together for x∗, λ and μ.

13. KKT in Action

Let us re-run the two 1D examples through the KKT machinery, trying both possibilities for complementary slackness.

Case 2: minimize x2 subject to x≥2

Here h(x)=x−2≥0 and

L(x,μ)=x2−μ(x−2)
  • Stationarity: 2x−μ=0
  • Complementary slackness: μ(x−2)=0
  • Dual feasibility: μ≥0; primal feasibility: x≥2
Branch Consequence Verdict
μ=0 (inactive) 2x=0⇒x=0, but x≥2 fails Rejected (infeasible)
x=2 (active) μ=2x=4≥0, feasible Accepted

So x∗=2, μ∗=4. Check with the parallel-gradient picture: ∇f(2)=4=μ∇h=4⋅1. This also explains the earlier puzzle: the gradient of f is nonzero at the optimum because the constraint is pushing back with force μ=4.

Case 3: minimize x2 subject to x≥−2

Here h(x)=x+2≥0 and

L(x,μ)=x2−μ(x+2)
  • Stationarity: 2x−μ=0
  • Complementary slackness: μ(x+2)=0
Branch Consequence Verdict
μ=0 (inactive) x=0, and h(0)=2>0 is feasible Accepted
x=−2 (active) μ=2x=−4<0, violates dual feasibility Rejected

So x∗=0, μ∗=0: the constraint is inactive, exactly as the picture suggested.

14. Looking Ahead to SVM

Now apply the KKT conditions to the hard-margin SVM. The variables are (θ,b), there are no equality constraints, and there are n inequality constraints

hi​(θ,b)=yi​(xi⊤​θ+b)−1≥0,i=1,…,n

The Lagrangian is

L(θ,b,μ)=θ⊤θ−i=1∑n​μi​[yi​(xi⊤​θ+b)−1]

The KKT conditions read:

  • Stationarity in θ: ∇θ​L=2θ−∑i​μi​yi​xi​=0⇒θ=21​∑i​μi​yi​xi​
  • Stationarity in b: ∂b∂L​=−∑i​μi​yi​=0
  • Primal feasibility: yi​(xi⊤​θ+b)≥1
  • Complementary slackness: μi​[yi​(xi⊤​θ+b)−1]=0
  • Dual feasibility: μi​≥0

Complementary slackness explains the name support vector. A data point can have μi​>0 only if its constraint is active, i.e. yi​(xi⊤​θ+b)=1: the point lies exactly on a margin hyperplane. Every other point is inactive (μi​=0) and does not contribute to θ at all. The solution is built only from the points sitting on the margin, which are the circled points in the first figure. The details and further simplification of these equations continue in the next lecture.

15. Quick Summary

Problem type Condition for a candidate optimum
Unconstrained ∇f(x∗)=0
Equality constrained, g(x)=0 ∇f=λ∇g and g(x)=0 (from L=f−λg)
Inequality constrained, h(x)≥0 All four KKT conditions
Symbol Meaning
λi​ Multiplier of equality constraint gi​ (any sign)
μj​ Multiplier of inequality constraint hj​≥0 (must be ≥0)
Active hj​(x∗)=0, behaves like an equality
Inactive hj​(x∗)>0, can be ignored, μj​=0

Storyline: SVM → quadratic program with linear inequality constraints → gradient =0 is not enough → Lagrange multipliers (equalities) → active/inactive constraints → complementary slackness and sign condition → KKT.
