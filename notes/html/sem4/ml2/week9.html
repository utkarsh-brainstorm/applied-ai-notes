1. Why Do We Need Neural Networks

Imagine you are a surveyor who has to draw a fence between two kinds of farmland. Soil type x lies on one side, soil type o on the other. The fence cannot be a straight line, because the two regions wind around each other.

We already know one tool for this: the kernel SVM, which can carve out curved boundaries. But two things make it uncomfortable in general:

  • The boundary can be very complex.
  • The data set can have a huge number of classes (millions, say). We still want a way to train a classifier that learns the classification boundary from data.

Two kinds of boundary are used as running examples.

A general, continuous non-linear boundary

A piecewise linear boundary

Here the boundary is not smooth, but it is made of straight segments. Each segment separates the data in its own local region, so the whole boundary is a combination of three linear boundaries.

We start with the piecewise linear case. The question is: how do we build such a boundary, and how do we learn it from data?

2. Parameterizing a Piecewise Linear Function

Look at the piecewise linear boundary again. In one region the boundary is a line, in the next region it is another line, and in the third region a third line. So the boundary is a combination of 3 linear boundaries.

We cannot train a separate classifier on each piece, because we do not know in advance where the pieces are. Instead we parameterize one function f so that it is automatically piecewise linear.

Let the label be predicted from the input as y=f[x,ϕ], where ϕ holds all the parameters of the model. For simplicity, the input x has a single feature for now (many features come later).

We create three linear functions of x and take a linear combination of them, passing each one through an activation function a(⋅):

y=ϕ0​+ϕ1​a(θ10​+xθ11​)+ϕ2​a(θ20​+xθ21​)+ϕ3​a(θ30​+xθ31​)

Each inner expression is a linear function of x:

  • θ10​+xθ11​ is the first linear classifier,
  • θ20​+xθ21​ is the second,
  • θ30​+xθ31​ is the third.

If the boundary has many linear pieces, we just keep adding such terms, one per piece.

Note for Review: The board writes the last coefficient with the same name as the second one, and lists only ϕ0​,ϕ1​,ϕ2​ in the parameter set. With three hidden terms there must be four output coefficients, ϕ0​,ϕ1​,ϕ2​,ϕ3​. These notes use the corrected version. The same fix gives 10 parameters for this model in total.

3. The ReLU Activation Function

For piecewise linear boundaries, the activation function we use is the ReLU (Rectified Linear Unit), the most widely used activation function:

a(z)=ReLU(z)={z0​if z≥0if z<0​

Before 0 the value is always 0. After 0 it rises linearly with slope

Why ReLU keeps boundaries piecewise linear. ReLU is itself piecewise linear (two pieces, joined at z=0). Passing a linear function through it therefore does not turn a linear classifier into a smooth non-linear one. The result is still piecewise linear, with a single bend (a "kink") where the input to ReLU crosses zero.

ReLU as a hinge. For one hidden unit, a(θd0​+xθd1​) is flat (=0) until

x=−θd1​θd0​​

and after that it grows with slope θd1​ (for θd1​>0). Each hidden unit adds one bend to the function, and the output coefficient ϕd​ scales how steep that bend is, and flips it if ϕd​<0.

Note for Review: Pro-Tip: If ReLU were replaced by the identity a(z)=z, the whole expression would collapse to one straight line, because a sum of linear functions of x is linear. The non-linearity of a is what lets the units "bend" the output.

4. Learnable Parameters and the Training Objective

The model is

y=f[x,ϕ]

where the parameter vector collects every learnable number. For three hidden units:

ϕ={ϕ0​,ϕ1​,ϕ2​,ϕ3​,θ10​,θ11​,θ20​,θ21​,θ30​,θ31​}

Each different choice of these numbers gives a different piecewise linear function. So the boundary's shape changes as the parameters change, and depending on the data set we must learn the parameters to get the best boundary.

Training. Suppose we are solving a (piecewise linear) regression or classification problem with n data points. For the i-th point, the prediction is

y^​i​=f[xi​,ϕ]

and the ground-truth label is yi​. The loss over the data set is

n1​i=1∑n​(y^​i​−yi​)2

and training means minimizing it over all the parameters, using any of the optimization techniques we have studied:

n1​i=1∑n​(y^​i​−yi​)2⇒ϕmin​n1​i=1∑n​(f[xi​,ϕ]−yi​)2

The minimizer gives the optimal parameters for the given data set.

Note for Review: The symbol ϕ is used in two ways in the notes: as the whole parameter set (bold, ϕ) and as the output-layer weights ϕ0​,ϕ1​,… (plain, with an index). Context makes it clear, but watch out when reading equations.

5. Separating the Input from the Model

Managing a long expression with many terms is tedious. Keep two hidden terms to simplify, and give the inner pieces names:

y​=ϕ0​+ϕ1​a(θ10​+xθ11​)+ϕ2​a(θ20​+xθ21​)=ϕ0​+ϕ1​h1​+ϕ2​h2​​

with

h1​=a(θ10​+xθ11​),h2​=a(θ20​+xθ21​)

Now x is the input and y is the output, and the box between them depends only on the learnable parameters ϕ:

So what is inside the box? Look at the first term. The constant input 1 is multiplied by θ10​, the input x is multiplied by θ11​, and the two are added. The sum θ10​+xθ11​ is passed through the activation a, which gives h1​. The same happens for h2​ with θ20​,θ21​. Finally h1​ is multiplied by ϕ1​, h2​ by ϕ2​, a constant 1 is multiplied by ϕ0​, and everything is added to give y.

Since the activation is applied at every unit, we stop drawing a as a separate box and fold it into the unit. That gives the compressed picture, which is our first neural network:

Note for Review: This network has one layer of intermediate units (the h's), which is why it is called a shallow neural network.

7. The Biological Neuron Inspiration

Why are these things called neural networks?

There are billions of neurons in the brain, interconnected with each other, and together they process information from the sensory organs. A single neuron:

  1. Receives information from other neurons through action potentials.
  2. At the synapses, neurotransmitters allow the action potential, which carries the information, to pass from one neuron to the next. The density of neurotransmitters at each synapse effectively gives a different weight to the signal coming from each neighbour.
  3. Combines the weighted signals (a linear combination), and can add some bias of its own.
  4. Processes the result with a non-linear activation, and passes the output on to other neurons, for which it becomes an input.

Depending on the task, these weights get adjusted, so that the organism can correctly interpret what is being communicated to it.

Say the neuron receives signals x1​,x2​,x3​,x4​ from four neurons, with weights w1​,w2​,w3​,w4​ and own bias w0​. Then

h1​=w0​+x1​w1​+x2​w2​+x3​w3​+x4​w4​,y1​=a(h1​)

Biology Artificial neuron
Signals from other neurons Inputs x1​,…,x4​
Neurotransmitter density at each synapse Weights w1​,…,w4​
Neuron's own offset Bias w0​
Combining the incoming signals Sum h1​=w0​+∑i​xi​wi​

Now go back to the network from Section 5. The hidden unit h1​ receives x and the constant 1, gives them weights, sums them, applies a, and its output becomes an input for the next neuron (here the output unit). It is exactly the same picture.

Note for Review: Think of a neuron as a tiny committee member: it listens to all of its inputs, trusts some more than others (the weights), adds its own mood (the bias), and then decides how loudly to speak up (the activation).

8. The Shallow Neural Network

Now take one input x (plus the bias unit) and one layer of D neurons. Each neuron gets the same inputs but uses its own weights, so each processes the input differently.

The d-th hidden unit (neuron) computes

hd​=a(θd0​+xθd1​),d=1,…,D

and the output is

y=ϕ0​+ϕ1​h1​+ϕ2​h2​+⋯+ϕD​hD​

Different activations? In principle each neuron could use its own activation (say a sigmoid in one and a ReLU in another), but in practice all neurons in a layer use the same activation function.

Why add more neurons? More neurons means more learnable parameters. With a single hidden neuron there are only four parameters (θ10​,θ11​,ϕ0​,ϕ1​), and four numbers cannot represent a complex boundary. So we add neurons depending on the complexity of the model we need and on how many data points we have.

For one input and D hidden units the parameter count is

θd0​,θd1​2D​​+ϕ0​,…,ϕD​(D+1)​​=3D+1

(Check: D=1 gives 4 and D=3 gives 10, as before.)

Because there is only one hidden layer, this is called a shallow neural network.

9. More Than One Input Feature

With two input features x_1, x_2 the idea is the same: each neuron receives all the inputs, and each connection has its own weight. Take three hidden neurons:

Each hidden unit is

h1​=a(θ10​+θ11​x1​+θ12​x2​)h2​=a(θ20​+θ21​x1​+θ22​x2​)h3​=a(θ30​+θ31​x1​+θ32​x2​)

and the output multiplies each hd​ by ϕd​ and adds the bias ϕ0​:

y=ϕ0​+ϕ1​h1​+ϕ2​h2​+ϕ3​h3​

This way we can include as many input features as we want, and as many neurons as we want.

10. Layers and Terminology

Take the network of Section 9 and name its parts:

Layer What it is In the Section 9 network
Input layer The input features, plus the bias unit x1​,x2​ and the constant 1
Hidden layer Intermediate quantities derived from the inputs, used later to build the output 3 neurons h1​,h2​,h3​
Output layer The final prediction 1 unit y

They are called hidden because they are neither inputs nor outputs: they live in between.

  • Shallow neural network: a network with a single hidden layer.
  • Deep neural network: a network with more hidden layers.
  • You can add as many hidden layers (and as many neurons per layer) as the data set demands.

11. Going Deep by Stacking

The "naive" way to go deeper is to chain two shallow networks. With one input x and no bias drawn for the time being (to keep the figure tidy), the first network has 3 neurons and produces y. The second network treats y as its input, has 3 neurons of its own, and produces y′.

First network:

h1​=a(θ10​+xθ11​),h2​=a(θ20​+xθ21​),h3​=a(θ30​+xθ31​)y=ϕ0​+ϕ1​h1​+ϕ2​h2​+ϕ3​h3​

Second network (its input is y):

h1′​=a(θ10′​+yθ11′​),h2′​=a(θ20′​+yθ21′​),h3′​=a(θ30′​+yθ31′​)y′=ϕ0′​+ϕ1′​h1′​+ϕ2′​h2′​+ϕ3′​h3′​

This is not the conventional way to build a deep network. We are throwing the rich hidden vector (h1​,h2​,h3​) away and passing only the single number y forward.

Note for Review: Pro-Tip: Think of the stacked version as sending a whole orchestra's performance through a single microphone before the next stage hears it. Conventional deep networks instead pass the entire hidden layer to the next layer, as the next section shows.

12. The Conventional Deep Network

In a conventional deep network, the outputs of all neurons in one layer become the inputs of every neuron in the next layer. Because every neuron is connected to all neurons in the previous layer, such a network is called a fully connected neural network.

Example used here:

Layer Contents

1st hidden 4 neurons h11​,h12​,h13​,h14​
2nd hidden 4 neurons h21​,h22​,h23​,h24​
3rd hidden 3 neurons h31​,h32​,h33​
Output layer 2 outputs y1​,y2​

Notation: hkj​ is the j-th neuron of the k-th hidden layer. The vector h1​ collects the outputs of layer 1, h2​ those of layer 2, h3​ those of layer 3, and y is the output.

Several outputs are natural: a regression target may be a vector, or there may be several classes (say two) and we want a score for each.

13. Matrix Notation

Writing every neuron separately becomes unmanageable, so we vectorize. We derive it for the first hidden layer.

Step 1 — one neuron at a time. Input vector and the weights of neuron 1:

x=⎣⎡​x1​x2​x3​​⎦⎤​,θ1​=⎣⎡​θ11​θ12​θ13​​⎦⎤​h11​=a(θ10​+θ11​x1​+θ12​x2​+θ13​x3​)=a(θ10​+θ1T​x)

The sum of products is just the inner product of θ1​ and x. The other three neurons are identical, with their own weight vectors:

h12​=a(θ20​+θ21​x1​+θ22​x2​+θ23​x3​)=a(θ20​+θ2T​x),θ2​=⎣⎡​θ21​θ22​θ23​​⎦⎤​h13​=a(θ30​+θ3T​x),h14​=a(θ40​+θ4T​x)

Note that x is the same in all four.

Step 2 — stack the four neurons into a vector.

h1​=⎣⎡​h11​h12​h13​h14​​⎦⎤​=a⎝⎛​⎣⎡​θ10​+θ1T​xθ20​+θ2T​xθ30​+θ3T​xθ40​+θ4T​x​⎦⎤​⎠⎞​

(The activation a is applied element-wise.)

Step 3 — split the biases from the weighted parts.

h1​=a⎝⎛​⎣⎡​θ10​θ20​θ30​θ40​​⎦⎤​+⎣⎡​θ1T​xθ2T​xθ3T​xθ4T​x​⎦⎤​⎠⎞​

The first vector is 4×1 and is called β0​ (the bias vector of layer 1).

Step 4 — pull the common factor x out. Since x appears in all four terms, the second vector is a matrix times x:

h1​=a⎝⎛​β0​+⎣⎡​θ1T​θ2T​θ3T​θ4T​​⎦⎤​x⎠⎞​=a(β0​+Ω0​x)∈R4×1

where the weight matrix has one row per neuron:

Ω0​=⎣⎡​θ11​θ21​θ31​θ41​​θ12​θ22​θ32​θ42​​θ13​θ23​θ33​θ43​​⎦⎤​∈R4×3

Note for Review: On the board the fourth row was first forgotten, then added. Ω0​ must be 4×3: 4 neurons in the layer (rows), 3 inputs feeding it (columns).

Step 5 — the other layers. The output of one layer is the input of the next, so we simply replace x by h1​ (and the shapes change):

  • Second hidden layer (4 neurons; previous layer has 4 neurons):
h2​=a(β1​+Ω1​h1​),β1​∈R4×1,Ω1​∈R4×4
  • Third hidden layer (3 neurons; previous layer has 4):
h3​=a(β2​+Ω2​h2​),β2​∈R3×1,Ω2​∈R3×4
  • Output layer (2 units; previous layer has 3). Here we choose not to apply an activation in the last layer:
y=β3​+Ω3​h3​,β3​∈R2,Ω3​∈R2×3

Shape rule to remember:

Ωk​∈R(neurons in layer k+1)×(neurons in layer k),βk​∈R(neurons in layer k+1)×1

where "layer 0" is the input layer.

14. A Numeric Walk-Through of One Layer

Check the matrix form of layer 1 with real numbers. Take

x=⎣⎡​12−1​⎦⎤​,Ω0​=⎣⎡​1−101​012−1​2011​⎦⎤​,β0​=⎣⎡​20−11​⎦⎤​

Step 1 — matrix-vector product Ω0​x, row by row (each row is an inner product):

Ω0​x=⎣⎡​1⋅1+0⋅2+2⋅(−1)(−1)⋅1+1⋅2+0⋅(−1)0⋅1+2⋅2+1⋅(−1)1⋅1+(−1)⋅2+1⋅(−1)​⎦⎤​=⎣⎡​1+0−2−1+2+00+4−11−2−1​⎦⎤​=⎣⎡​−113−2​⎦⎤​

Step 2 — add the bias vector (pre-activations):

β0​+Ω0​x=⎣⎡​20−11​⎦⎤​+⎣⎡​−113−2​⎦⎤​=⎣⎡​112−1​⎦⎤​

Step 3 — apply ReLU element-wise:

h1​=a⎝⎛​⎣⎡​112−1​⎦⎤​⎠⎞​=⎣⎡​max(0,1)max(0,1)max(0,2)max(0,−1)​⎦⎤​=⎣⎡​1120​⎦⎤​

The fourth neuron produced a negative pre-activation, so ReLU silenced it: it contributes nothing to the next layer for this particular input.

Note for Review: The result h1​ is a 4×1 vector, which is now the input of layer 2. There Ω1​ must be 4×4 so that Ω1​h1​ is 4×1. If the inner dimensions do not match, something is wrong with your shapes.

17. Practice Questions

1. Counting bends. A 1-D network has D ReLU hidden units, y=ϕ0​+∑d=1D​ϕd​ReLU(θd0​+xθd1​). A colleague claims it can produce a function with D+5 linear pieces if you choose the parameters cleverly. Do you agree? Argue using the kink locations. Then explain what happens to the number of pieces if two hidden units happen to have the same kink position, and what happens if you replace ReLU by the identity function.

2. Layer budget. A fully connected network has 10 inputs, hidden layers of widths 20, 15 and 5, and 3 outputs. (a) Write the shape of every Ωk​ and βk​. (b) Which layer holds the most parameters? (c) If you may add exactly one neuron to one hidden layer, which choice adds the most new parameters, and which adds the fewest? Justify with the shape rule.

3. The bottleneck. In Section 11 two shallow networks are chained through the scalar y. Suppose two different inputs xa​=xb​ happen to give the same value y(xa​)=y(xb​) in the first network. Can the second network ever distinguish them? Compare this with a conventional deep network that passes the whole vector h1​∈R3 forward. What does this tell you about why width matters in the middle of a network?

4. Silent neurons. In Section 14 the fourth neuron of layer 1 outputs 0 for the given x. (a) For that input, what is the effect of the weights θ41​,θ42​,θ43​ on the final output y (use the chain of equations in Section 13)? (b) If a neuron produced 0 for every training example, what does it contribute to the model, and what does that say about the effective capacity of the network compared with the raw parameter count?

5. Reverse engineering. A fully connected network has 3 inputs, two hidden layers of equal width w, and 1 output, and it has exactly 73 trainable parameters (weights and biases). Find w. Then say how many parameters you would have if you added a third hidden layer of the same width w.
