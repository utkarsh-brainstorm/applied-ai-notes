Why Kernels Exist

We are given a data set

X={x1​,x2​,…,xn​},xi​∈Rd

where each data point lives in a d-dimensional space. In many classification problems the two classes are not linearly separable in Rd — no straight line (or hyperplane) can split them.

The idea: map every data point to a new, higher-dimensional space Rm with m>d:

ϕ:X→Rm,m>d

In that bigger space the two classes become linearly separable.

A tiny picture of "lifting"

Take 1-D points: the inner class sits near 0, the outer class far from 0. No single threshold on the line separates them. Add one new coordinate, x↦(x,x2), and a horizontal line does the job.

The dashed line (separating hyperplane) lives in the lifted space.

The catch — and the way out

Do we actually need the explicit mapping ϕ? No. All we need is a way to compare two data points in the higher-dimensional space, i.e. a similarity function.

Symbol Meaning
X the data set {x1​,…,xn​}, with xi​∈Rd
ϕ feature map X→Rm, m>d
K kernel K:X×X→R, returns a scalar similarity

The Kernel Trick Inside the SVM

Recall the SVM optimisation problem. The lecture writes it schematically as

w,bmin​w⊤w−i=1∑n​αi​yi​(xi⊤​w−b)⋯
  • w,b are the primal variables.
  • αi​ (one per data point, i=1,…,n) are the dual variables (Lagrange multipliers).

Note for Review — Pro-Tip: the schematic form above drops constants. The complete Lagrangian is L(w,b,α)=21​w⊤w−∑i​αi​[yi​(xi⊤​w−b)−1] with αi​≥0. The 21​ and the "−1" are what produce the 21​ and the ∑i​αi​ in the dual below.

Applying the KKT conditions

Setting the derivatives of L to zero:

∂w∂L​=w−i=1∑n​αi​yi​xi​=0⇒w=i=1∑n​αi​yi​xi​∂b∂L​=i=1∑n​αi​yi​=0

Substitute w back. Each of the two quadratic pieces becomes a double sum:

w⊤w=i∑​j∑​αi​αj​yi​yj​xi⊤​xj​,i∑​αi​yi​xi⊤​w=i∑​j∑​αi​αj​yi​yj​xi⊤​xj​

so 21​S−S+b∑i​αi​yi​+∑i​αi​ with S the double sum, and the b-term vanishes because ∑i​αi​yi​=0. What remains is the dual cost function:

i∑​αi​−21​i∑​j∑​αi​αj​yi​yj​⟨xi​,xj​⟩

The key observation

In the dual, the data points appear only through the inner product ⟨xi​,xj​⟩ — i.e. only through a similarity between pairs of points.

So to work in the lifted space we just replace that similarity by the similarity of the lifted points:

⟨xi​,xj​⟩⟶K(ϕ(xi​),ϕ(xj​))=ϕ(xi​)⊤ϕ(xj​)

No explicit ϕ is ever needed if we can compute K directly from the original points. That is the kernel trick.

What Exactly Is a Kernel

A kernel K is simply a function that takes two data points as input and returns a scalar (their similarity):

K:X×X→R

Example 1 — Polynomial kernel

K(xi​,xj​)=(⟨xi​,xj​⟩+c)2

The power 2 can be any other power (4, 6, …). The same formula gives similarity in either space:

  • original space: plug in xi​,xj​;
  • higher-dimensional space: plug in ϕ(xi​),ϕ(xj​).

The remarkable fact (seen in the previous class) is that this can be written as

K(xi​,xj​)=ϕ(xi​)⊤ϕ(xj​)

Worked check (d=2, power 2). Let x=(x1​,x2​), x′=(x1′​,x2′​) and put a=x1​x1′​, b=x2​x2′​. Then

(x⊤x′+c)2=(a+b+c)2=a2+b2+c2+2ab+2ac+2bc=x12​x1′2​+x22​x2′2​+2x1​x2​x1′​x2′​+2cx1​x1′​+2cx2​x2′​+c2

This is exactly ϕ(x)⊤ϕ(x′) for

ϕ(x)=(x12​,x22​,2​x1​x2​,2c​x1​,2c​x2​,c)⊤,

so a 2-D input is lifted to m=6 dimensions — yet computing the kernel only costs one dot product in R2 plus a square.

Example 2 — Gaussian kernel

K(xi​,xj​)=exp(−2σ2∥xi​−xj​∥22​​)

Another way of measuring similarity: close points give a value near 1, distant points a value near 0.

Why is it called a "trick"?

To get the similarity of two points in the higher-dimensional space, we only need the original data points and the kernel formula. We never need to know — or compute — the mapping ϕ.

The open question: why does such a ϕ exist at all for a given kernel formula? The next sections answer it with the Mercer theorem.

Positive Definite Kernels

Let the kernel be K:X2→R, where X2 is shorthand for X×X. Given X={x1​,…,xn​}, compute the similarity between all pairs (xi​,xj​), i,j∈{1,…,n}, and stack them into the kernel matrix (a.k.a. Gram matrix):

K=⎣⎡​K(x1​,x1​)⋮K(xn​,x1​)​⋯⋱⋯​K(x1​,xn​)⋮K(xn​,xn​)​⎦⎤​∈Rn×n

(Row 1 holds the similarity of x1​ with every point; the last entry of the last row is the similarity of xn​ with itself. There are n points and every pair is compared, hence n×n.)

Symmetric kernel

Similarity of xi​ to xj​ should equal similarity of xj​ to xi​:

K(xi​,xj​)=K(xj​,xi​)for all pairs of data points

The polynomial and Gaussian kernels above are both symmetric.

Positive definite and positive semi-definite

Type Condition on the kernel matrix
Positive definite (PD) c⊤Kc>0 for every non-zero c∈Rn
Positive semi-definite (PSD) c⊤Kc≥0 for every c∈Rn

Here c is any n×1 vector. Since the kernel is represented by a matrix, we use "PSD kernel" and "PSD matrix" interchangeably.

Why do we care? For a symmetric PSD kernel matrix we can always find the corresponding ϕ — this is exactly what the Mercer theorem says.

Worked check of PSD

Take K=[21​12​] and any c=(c1​,c2​)⊤:

c⊤Kc=[c1​​c2​​][2c1​+c2​c1​+2c2​​]=2c12​+2c1​c2​+2c22​=c12​+c22​+(c1​+c2​)2≥0

A sum of squares — so K is PSD. (We'll reuse this matrix later.)

The Mercer Theorem

Mercer's theorem. Let K:X2→R be a symmetric kernel which is positive semi-definite. Then there exist mappings ϕi​ and scalars λi​≥0 such that, for any two data points x and x′,

K(x,x′)=∑i​λi​ϕi​(x)ϕi​(x′)

In words: symmetric + PSD ⇒ the kernel is secretly a dot product in some feature space. The proof will even show how to compute the map.

Proof Toolkit Eigen Decomposition

For the proof we work with the kernel matrix with the two properties we are given:

K∈Rn×n,K⊤=K,c⊤Kc≥0∀c∈Rn

Eigenvalues and eigenvectors (quick refresher)

A vector v is an eigenvector of K with eigenvalue λ if

Kv=λv

Geometrically: for most vectors, multiplying by K turns them to point in a new direction. Eigenvectors are the special ones where Kv points along the same direction as v — only stretched or shrunk (by the scalar λ).

Concrete picture with K=[21​12​]:

  • u=(1,0) gives Ku=(2,1) — direction changes, so u is not an eigenvector.
  • v=(1,1) gives Kv=(3,3)=3v — same direction, so v is an eigenvector with λ=3.

An n\times n matrix has at most n distinct eigenvalues, with corresponding eigenvectors:

Kv1​=λ1​v1​,…,Kvn​=λn​vn​

Clubbing all n equations into one

Place the eigenvectors as columns of one matrix and the eigenvalues on a diagonal:

K[v1​⋯vn​]=[v1​⋯vn​]⎣⎡​λ1​0​⋱​0λn​​⎦⎤​

(Multiply out both sides: the k-th column of each side is Kvk​ and λk​vk​, so you recover all n equations.) In short,

KV=VD,V=[v1​⋯vn​],D=diag(λ1​,…,λn​)

Eigenvectors belonging to distinct eigenvalues are linearly independent, so V is invertible. Multiply on the right by V−1:

KVV−1=VDV−1⇒K=VDV−1

This is the eigenvalue–eigenvector decomposition of K.

Why can we order the eigenvalues, and why are they ≥0?

  • For a general matrix, eigenvalues can be complex, so they cannot be ordered.
  • For a symmetric matrix, eigenvalues are always real.
  • For a PSD matrix they are moreover non-negative.

So we may order them: λ1​≤λ2​≤⋯≤λn​.

Proof that λ≥0. Start from Kv=λv and multiply by v⊤ on the left:

v⊤Kv=λv⊤v

The left side is ≥0 by the PSD condition (take c=v). And v⊤v=∥v∥2>0 for an eigenvector (v=0). Therefore

Eigenvectors of a symmetric matrix are orthogonal

Let K⊤=K, take two distinct eigenvalues λi​=λj​ with eigenvectors vi​,vj​:

Kvi​=λi​vi​,Kvj​=λj​vj​

Take the inner product of the first equation with vj​ (the inner product is symmetric, and λi​ is a scalar so it pulls out):

⟨vj​,Kvi​⟩=⟨vj​,λi​vi​⟩⇒⟨Kvi​,vj​⟩=λi​⟨vi​,vj​⟩

Apply the definition of the inner product, ⟨a,b⟩=a⊤b:

(Kvi​)⊤vj​=λi​vi⊤​vj​⇒vi⊤​K⊤vj​=λi​vi⊤​vj​

Use K⊤=K, then use Kvj​=λj​vj​:

vi⊤​Kvj​=λi​vi⊤​vj​⇒vi⊤​λj​vj​=λi​vi⊤​vj​⇒λj​vi⊤​vj​=λi​vi⊤​vj​

Bring everything to one side:

(λi​−λj​)vi⊤​vj​=0

Because λi​=λj​, the bracket is non-zero, hence

vi⊤​vj​=0(i=j)​

Eigenvectors can be scaled to unit length, so

⟨vi​,vj​⟩={01​i=ji=j​

Note for Review — Pro-Tip: this often appears on exams as "why are the eigenvectors of a symmetric matrix orthogonal?". The whole proof is the one-liner (λi​−λj​)vi⊤​vj​=0. If an eigenvalue is repeated you simply choose an orthonormal basis inside that eigenspace (spectral theorem), so V is still orthonormal.

Proof of the Mercer Theorem

Step 1 — V is orthonormal

The columns of V=[v1​⋯vn​] are mutually orthogonal and of unit length, so V is an orthonormal matrix:

V⊤V=I⇒V−1=V⊤

Hence the decomposition becomes

K=VDV−1=VDV⊤

Step 2 — Split D into two square roots

D is diagonal, so D1/2 just takes the square root of each diagonal entry (real, because all λl​≥0):

D1/2=⎣⎡​λ1​​0​⋱​0λn​​​⎦⎤​,D=D1/2D1/2

Therefore

K=VD1/2D1/2V⊤

Step 3 — Rewrite as "something transposed times something"

Use the identity AB=(B⊤A⊤)⊤ with A=VD1/2 and B=D1/2V⊤. Since D1/2 is diagonal, (D1/2)⊤=D1/2, so

A=VD1/2=(D1/2V⊤)⊤

and

Step 4 — Read off one entry

The (i,j) entry of a product is row i of the left factor times column j of the right factor. Row i of (D1/2V⊤)⊤ is the transpose of column i of D1/2V⊤, so

Kij​=((D1/2V⊤):i​)⊤(D1/2V⊤):j​

Define the feature vector of data point xi​ as the i-th column of D1/2V⊤:

θ(xi​):=(D1/2V⊤):i​

Then

Kij​=K(xi​,xj​)=θ(xi​)⊤θ(xj​)​

Stacking the vectors θ(xi​)⊤ as the rows of a matrix Θ gives Θ=VD1/2 and

K=ΘΘ⊤

Step 5 — The same result from the outer-product form (entry by entry)

Multiply the three matrices V, D, V⊤ explicitly:

K=VDV⊤=[v1​⋯vn​]⎣⎡​λ1​0​⋱​0λn​​⎦⎤​⎣⎡​v1⊤​⋮vn⊤​​⎦⎤​

First, VD=[λ1​v1​⋯λn​vn​] (each column is scaled by its eigenvalue). Multiplying by the stacked rows vl⊤​ adds up one rank-one matrix per eigenvector:

K=l=1∑n​λl​vl​vl⊤​

Here vl​ is the whole l-th eigenvector and vl​(i) denotes its i-th entry. The (i,j) entry of vl​vl⊤​ is vl​(i)vl​(j), so

[K]ij​=K(xi​,xj​)=(l=1∑n​λl​vl​vl⊤​)ij​=l=1∑n​λl​vl​(i)vl​(j)

Split each λl​ into λl1/2​λl1/2​ (legal because λl​≥0):

[K]ij​=l=1∑n​λl1/2​vl​(i)λl1/2​vl​(j)

A sum of products of matching entries is the inner product of two vectors:

[K]ij​=[λ11/2​v1​(i)​λ21/2​v2​(i)​⋯​λn1/2​vn​(i)​]⎣⎡​λ11/2​v1​(j)λ21/2​v2​(j)⋮λn1/2​vn​(j)​⎦⎤​=θ(xi​)⊤θ(xj​)

with

θ(xi​)=(λ1​​v1​(i),λ2​​v2​(i),…,λn​

Define ϕl​:=vl​, i.e. ϕl​(xi​)=vl​(i). Then Step 5 reads

K(xi​,xj​)=l=1∑n​λl​ϕl​(xi​)ϕl​(xj​),λl​≥0

which is exactly the Mercer form. The explicit feature map is θ(x)=(λl​​ϕl​(x))l​. ■

(Notation reminder: in the derivation the eigenvectors play the role of the ϕl​ in the theorem, while the final lifted vector is called θ.)

Fully worked numerical example

Take K=[21​12​] (symmetric, PSD as checked earlier).

Eigenvalues. Solve det(K−λI)=(2−λ)2−1=0⇒λ=1 or 3. Ordered: λ1​=1, λ2​=3.

Eigenvectors (unit length). λ1​=1: (K−I)v=0⇒v1​=2​1​(1,−1)⊤. λ2​=3: v2​=2​1​(1,1)⊤. Check v1⊤​v2​=21​(1−1)=0 ✓.

V=2​1​[1−1​11​],D=[10​03​]

Verify K=VDV⊤ (matrix multiplication shown).

VD=2​1​[1⋅1−1⋅1​1⋅31⋅3​]=2​1​[1−1​33​]VDV⊤=2​1​[1−1​33​]⋅2​1​[11​−11​]=21​[1+3−1+3​−1+31+3​]=[21​12​]✓

Feature vectors. Using θ(xi​)=(λ1​​v1​(i),λ2​​v2​(i))⊤:

θ(x1​)=(1⋅2​1​,3​⋅2​1​)⊤,θ(x2​)=(1⋅2​−1​,3​⋅2​1​)⊤

Check the dot products.

θ(x1​)⊤θ(x1​)=21​+23​=2=K11​,θ(x1​)⊤θ(x2​)=−21​+23​=1=K12​,θ(x2​)⊤θ(x2​)=21​+23​=2=K22​

All entries of K are recovered as dot products of explicit feature vectors ✓.

Why non-negative eigenvalues matter

If some λl​ were negative, then λl​​ would be imaginary: there would be no real vector θ(x) and the "similarity" could even turn negative for a point with itself (Kii​=∥θ(xi​)∥2 must be ≥0). The PSD condition c⊤Kc≥0 is precisely what guarantees λl​≥0, hence real feature vectors and non-negative self-similarity.

Putting Kernels to Work

Recipe:

  1. Start with your data points X={x1​,…,xn​}.
  2. Choose a kernel K (polynomial, Gaussian, Laplacian, sigmoid, …).
  3. Build the kernel matrix K∈Rn×n using that formula.
  4. Compute its eigenvalue–eigenvector decomposition.
  5. Build the mapping θ (the "ϕ") from it — this lifts your points to a higher-dimensional space.
  6. Solve any machine learning task there.

There are two routes: if the algorithm only needs similarities (SVM dual, kernel regression below) you go directly from K to the task and skip the eigen-step; if you explicitly need the lifted points, you go via the decomposition.

A Zoo of Kernels

Kernel Formula Parameters
Polynomial K(x,x′)=(x⊤x′+c)d constant c, degree d
Gaussian K(x,x′)=exp(−2σ2∥x−x′∥22​​) width σ
Laplacian K(x,x′)=exp(−2σ2∥x−x′∥12​​) width σ
Sigmoid K(x,x′)=tanh(ax⊤x′+b) a,b>0

All of these can map data to high-dimensional spaces; with a kernel in hand you get similarity scores in the lifted space without knowing ϕ. If you do need ϕ, build the kernel matrix and run the eigen-decomposition from the proof above.

Radially symmetric kernels

For the Gaussian kernel put r=∥x−x′∥2​, the distance between the two points. Then the kernel is a function of the distance alone:

K(x,x′)=exp(−2σ2r2​)=K(r)

Every pair of points at the same distance r gets the same similarity, so such kernels are called radially symmetric. The width σ controls how quickly similarity dies off:

Small σ: only very close neighbours count as similar. Large σ: even far-away points still look similar.

Note for Review — Pro-Tip: two caveats worth remembering. (1) The Laplacian kernel is written above as in the lecture; the more common textbook form uses the unsquared one-norm, exp(−∥x−x′∥1​/σ). (2) Polynomial and Gaussian kernels are always PSD, but the sigmoid kernel is PSD only for some choices of a,b — so "check PSD before you trust a kernel" is a genuine rule, not a formality. The Gaussian kernel's feature space is in fact infinite-dimensional, which is why we never want to construct ϕ explicitly for it.

Kernel Linear Regression

The kernel method applies to any machine-learning problem: we just map the data to a higher-dimensional space, and the analysis stays the same. Let's redo (ridge) linear regression with kernels.

Ordinary linear regression first

Data set: S={(x1​,y1​),…,(xn​,yn​)} with continuous targets yi​. The hypothesis is a linear projection:

h(xi​)=w⊤xi​=y^​i​≈yi​

We want y^​i​ as close as possible to the ground truth yi​. To avoid over-fitting we add a regularisation term on w:

ℓ(w)=21​i=1∑n​(y^​i​−yi​)2+2λ​w⊤w=21​i=1∑n​(w⊤xi​−yi​)2+2λ​w⊤w

Set the gradient to zero:

∇ℓ(w)=i=1∑n​(w⊤xi​−yi​)xi​+λw=0⟹w=−λ1​i=1∑n​(w⊤xi​−yi​)xi​

Enter the kernel: replace xi​ by ϕ(xi​)

h(ϕ(xi​))=w⊤ϕ(xi​),w=−λ1​i=1∑n​(w⊤ϕ(xi​)−yi​)ϕ(xi​)

Absorb the scalar −λ1​(w⊤ϕ(xi​)−yi​) into a single number ai​:

w=i=1∑n​ai​ϕ(xi​)=Φ⊤a

where Φ∈Rn×m has ϕ(xi​)⊤ as its i-th row (first row ϕ(x1​)⊤, second row ϕ(x2​)⊤, …) and a=(a1​,…,an​)⊤. The optimal weight vector is a linear combination of the lifted data points.

Rewrite the loss in terms of a

Substitute w=Φ⊤a, so w⊤ϕ(xi​)=a⊤Φϕ(xi​) and w⊤w=a⊤ΦΦ⊤a:

J(a)=21​i=1∑n​(a⊤Φϕ(xi​)−yi​)2+2λ​a⊤ΦΦ⊤a

Collect the n predictions into a vector, y^​=ΦΦ⊤a, and write the sum of squares as a norm, 21​(ΦΦ⊤a−y)⊤(ΦΦ⊤a−y), where y stacks all target values. Expanding:

J(a)=21​a⊤ΦΦ⊤ΦΦ⊤a−a⊤ΦΦ⊤y+21​y⊤y+2λ​a⊤ΦΦ⊤a

Now notice that the (i,j) entry of ΦΦ⊤ is ϕ(xi​)⊤ϕ(xj​)=K(xi​,xj​) — so ΦΦ⊤ is the kernel matrix K (in the proof above this is ΘΘ⊤). Therefore

J(a)=21​a⊤KKa−a⊤Ky+21​y⊤y+2λ​a⊤Ka​

The loss now depends on the data only through K.

Minimise over a

Using K=K⊤ (so ∇a​a⊤Ma=2Ma for symmetric M, and ∇a​a⊤Ky=Ky):

∇a​J=22​KKa−K⊤y+22λ​Ka=0KKa+λKa=K⊤y=Ky

Factor K out of the left side:

K(K+λI)a=Ky

Since K is invertible, cancel it:

(K+λI)a=y⟹a=(K+λI)−1y​

This is kernel linear regression: the parameters follow from the target vector and the kernel matrix alone. To predict at a new point x:

h(x)=w⊤ϕ(x)=i=1∑n​ai​ϕ(xi​)⊤ϕ(x)=i=1∑n​ai​K(xi​,x)

Note for Review — Pro-Tip: "Is K+λI invertible?" is a classic question. The eigenvalues of a PSD matrix K are ≥0, so those of K+λI are ≥λ>0 — it is always invertible when λ>0, even when K itself is singular. The regulariser is doing double duty: fighting over-fitting and keeping the algebra well-posed.

Takeaway of the whole module. Whenever we want classes to become linearly separable — or a fitting function to be linear in a lifted space although it is non-linear in the original — we use kernels: similarities in the high-dimensional space come directly from the original points, no mapping needed. If the mapping is needed, build the kernel matrix, eigen-decompose it, and reconstruct θ as in the Mercer proof. Next up: neural networks.

  1. The suspicious similarity table. A colleague proposes, for two data points, the kernel matrix K=[12​21​] ("a point is more similar to the other point than to itself!"). Find a vector c that proves it is not a valid kernel matrix, then explain — using what you know about the eigenvalues and about θ(xi​)⊤θ(xj​) — why no real feature vectors could ever produce it.

  2. Counting dimensions. For inputs in R3, the kernel (x⊤x′+c)2 corresponds to an explicit ϕ. How many coordinates does ϕ have? Now imagine inputs in R100 and a power of 6. Compare, in rough terms, the work of evaluating the kernel directly with the work of building ϕ and taking a dot product. What does this say about why the trick is worth the trouble — and what happens in the Gaussian case, where ϕ is infinite-dimensional?

  3. Dialing σ. Using a Gaussian kernel on n distinct training points, think about the two extremes σ→0 and σ→∞. What does the kernel matrix K approach in each case? What do the eigenvalues and feature vectors θ(xi​) look like? Combine this with a=(K+λI)−1y and h(x)=∑i​ai​K(xi​,x) to predict how the fitted function behaves on the training points and between them in each extreme.

  4. Duplicate points, different labels. Suppose two training points are identical (x1​=x2​) but have different targets y1​=y2​. What does this do to the kernel matrix K (rank, invertibility)? Why does the step "cancel K from K(K+λI)a=Ky" become dangerous, and what does a small λ>0 end up doing to the predicted values at that point? Argue from eigenvalues, not from the final formula.

  5. Kernels can be combined. Let K1​ and K2​ be PSD kernel matrices on the same points. (a) Using only the definition c⊤Kc≥0, show that K1​+K2​ is also PSD. (b) If θ1​(x) and θ2​(x) are feature maps for K1​ and K2​, construct a feature map for K1​+K2​ and verify it reproduces every entry. (c) Is "negative squared distance", K(x,x′)=−∥x−x′∥2, a valid kernel? Test it on two distinct points before answering.
