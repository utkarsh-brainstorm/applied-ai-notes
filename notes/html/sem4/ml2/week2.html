What Is an Optimization Problem?

At its core, optimization is about finding the input to a function that makes the function's output as large or as small as possible. Most of this material was already touched on in high school (11th/12th grade calculus), so the goal here is to refresh it quickly before machine-learning-specific complications get piled on top.

Start with the simplest possible setting: a function f:R→R, meaning it takes a single real number as input and produces a single real number as output. A concrete example used throughout this lecture is:

f(x)=x2+2x+3,x∈R

Both the input and the output here are scalars — single numbers, not vectors or matrices.

In machine learning, the overwhelming majority of problems are framed as minimization problems (minimizing a loss or cost function), even though the underlying mathematics works identically for maximization.

The Notation Zoo: min, max, argmin, argmax

Two closely related but distinct ideas need separate notation:

  • fmax​=maxx​f(x) — the maximum value that the function attains.
  • fmin​=minx​f(x) — the minimum value that the function attains.
  • x∗=argmaxx​f(x) — the location (the value of x) at which the maximum occurs.
  • x∗=argminx​f(x) — the location at which the minimum occurs.

Note for Review: This mix-up is a classic exam trap. min f(x) answers "how low does it go?" while argmin f(x) answers "where does it go that low?" One returns a function value, the other returns a point.

Finding Extrema with Derivatives

The standard recipe for locating a maximum or minimum of a single-variable function is to look for points where the function's slope is zero.

Why does this work? Consider approaching a point of minimum from the left:

Region relative to the minimum Sign of f′(x)
Just before the minimum Negative (function is decreasing)
Exactly at the minimum Zero
Just after the minimum Positive (function is increasing)

The slope transitions from negative to positive, passing through zero exactly at the minimum. The mirror image holds for a maximum:

Region relative to the maximum Sign of f′(x)
Just before the maximum Positive (function is increasing)
Exactly at the maximum Zero
Just after the maximum Negative (function is decreasing)

This gives the general recipe: differentiate the function, set the derivative to zero, and solve for x.

Worked Example — Minimizing a Parabola

Take f(x)=x2+2x+3 and find its minimum.

Step 1 — Differentiate:

dxdf(x)​=2x+2

Step 2 — Set the derivative to zero and solve:

2x+2=0⟹x∗=−1

Step 3 — Evaluate the function at the optimal point:

f(x∗)=(−1)2+2(−1)+3=1−2+3=2

So the function attains its minimum value of 2 at x∗=−1. Before x=−1 the slope is negative; after it, the slope is positive — confirming this is indeed a minimum, not just a stationary point.

Worked Example — Maximizing an Upside-Down Parabola

Now take f(x)=−x2+2x+1 and find its maximum.

Step 1 — Differentiate:

dxdf(x)​=−2x+2

Step 2 — Set the derivative to zero and solve:

−2x+2=0⟹x∗=1

The function increases before x=1 and decreases after it, confirming a maximum at x∗=1, with f(1)=−1+2+1=2.

When a Function Refuses to Behave: Multiple Extrema

Both worked examples above are unusually cooperative: each has exactly one stationary point, so setting the derivative to zero immediately identifies the global optimum. Real functions — and in particular, the loss surfaces of neural networks — are rarely this polite. A function can easily have multiple local minima and multiple local maxima, each corresponding to a point of zero slope.

The recipe still starts the same way — find every point where f′(x)=0 — but now there is an extra step:

  1. Find all stationary points (every x where f′(x)=0).
  2. Evaluate f(x) at each one.
  3. The stationary point with the smallest function value is the global minimum; the one with the largest value is the global maximum. All the others are merely local extrema.

Reading the curve left to right: the slope is negative, hits zero at the first (local) minimum, turns positive, hits zero again at a local maximum, turns negative, hits zero at a second minimum, and finally turns positive again on the far right. Every one of those zero-crossings is a stationary point, but only the deepest dip qualifies as the global minimum.

Telling Minima from Maxima: The Second Derivative Test

Once a stationary point is found, how do we know whether it's a minimum or a maximum without plotting the whole curve? The second derivative (curvature) settles it:

Second derivative at x∗ Interpretation Type of extremum
f′′(x∗)>0 Curving upward (like a bowl) Minimum
f′′(x∗)<0 Curving downward (like a dome) Maximum

Checking the two worked examples: for f(x)=x2+2x+3, f′′(x)=2>0, confirming a minimum; for f(x)=−x2+2x+1, f′′(x)=−2<0, confirming a maximum.

Leveling Up: Functions of Several Variables

Real machine learning models rarely depend on a single scalar input — a data point might have hundreds of features, and a model might have thousands (or millions) of parameters. So the next step is to generalize from f:R→R to functions that take a vector as input:

f:R2→R,f(x1​,x2​)=x12​+x22​+2

Here x1​ and x2​ are stacked into a vector x=[x1​x2​​]. Since x12​+x22​ is exactly the squared 2-norm of x, this function can be rewritten compactly as:

f(x)=x⊤x+2

With a single-variable function there was only one direction in which to measure slope. With two (or more) variables, there is a slope in each coordinate direction, captured by partial derivatives:

∂x1​∂f​=2x1​,∂x2​∂f​=2x2​

Setting both partial derivatives to zero simultaneously gives the stationary point:

∂x1​∂f​=0⟹x1∗​=0,∂x2​∂f​=0⟹x2∗​=0

Checking curvature in each direction, ∂x12​∂2f​=2>0 and ∂x22​∂2f​=2>0, so this is a point of minima.

The same idea extends to three variables, f:R3→R:

f(x1​,x2​,x3​)=x12​+x22​+x32​+3

...and beyond. In a large neural network, the loss function f(θ) might depend on a parameter vector θ∈Rn where n runs into the thousands or millions:

θmin​f(θ),θ∈Rn

Not every multivariable function separates as cleanly as the example above. Consider:

f(x1​,x2​)=x12​+2x22​+2x1​x2​+3

Here the partial derivatives are:

∂x1​∂f​=2x1​+2x2​=0⟹x1​+x2​=0∂x2​∂f​=4x2​+2x1​=0⟹x1​+2x2​=0

Unlike the earlier example, both equations now involve both variables — they must be solved simultaneously. This is still a manageable pair of linear equations, but the difficulty escalates quickly. For instance, with

f(x1​,x2​)=2x14​+3x23​+2x1​x2​+6

the resulting stationary-point equations,

8x13​+2x2​=0,9x22​+2x1​=0

are non-linear. Solving a handful of non-linear equations is already unpleasant; solving thousands of them — as would be required for a real neural network — is intractable by hand. This is precisely why practical machine learning relies on numerical optimization algorithms (like gradient descent) rather than directly solving the stationary-point equations, a topic for a later lecture.

The Gradient Vector

Rather than juggling every partial derivative separately, they are collected into a single vector called the gradient, denoted ∇f:

∇f=⎣⎡​∂x1​∂f​∂x2​∂f​​⎦⎤​

For a function of n variables, the gradient is an n×1 vector containing all n partial derivatives. Finding a stationary point of a multivariable function now becomes a single, compact statement:

∇f=0

Vectorizing Everything

Writing out x1​,x2​,x3​,… individually becomes unmanageable once a model has many parameters. The fix is to stack all the variables into a single vector x and re-express both the function and its gradient purely in terms of x.

Take f(x1​,x2​)=x12​+x22​+2x1​+3x2​+6. Grouping the linear coefficients into a vector b=[23​], this becomes:

f(x)=x⊤x+b⊤x+6

Its gradient, found term by term, is:

∇f=2x+b

This vectorized form is the version that will be reused for the rest of the course — occasionally we'll drop back down to individual partial derivatives to explain a new algorithm, but the endgame is always to express both the function and its gradient in terms of vectors.

Two Gradient Rules Worth Memorizing

Comparing the vectorized function to its gradient reveals three identities that recur constantly throughout machine learning:

Term Gradient with respect to x
x⊤x 2x
b⊤x (constant vector b) b
constant c 0

Note for Review: These three rules are the "multiplication table" of ML optimization — nearly every gradient derivation in this course (linear regression, logistic regression, ridge regression, and beyond) boils down to applying these three identities to a rewritten loss function.

The General Quadratic Form and Its Gradient

The next level of generality introduces a matrix into the function. Let A be a 2×2 matrix, b a 2×1 vector, and c a scalar constant:

A=[a1​a3​​a2​a4​​],b=[b1​b2​​],x=[x1​x2​​]f(x)=x⊤Ax+b⊤x+c

Dimensionally, x⊤Ax is (1×2)(2×2)(2×1)=1×1, so the whole expression is a scalar, exactly as required.

Deriving the gradient of x⊤Ax: Expanding the product explicitly,

x⊤Ax=a1​x12​+a3​x1​x2​+a2​x1​x2​+a4​x22​

Differentiating with respect to each variable:

∂x1​∂(x⊤Ax)​=2a1​x1​+a3​x2​+a2​x2​,∂x2​∂(x⊤Ax)​=a3​x1​+a2​x1​+2a4​x2​

Splitting each partial derivative into two pieces and regrouping by matrix, these two equations recombine into:

∇x​(x⊤Ax)=Ax+A⊤x=(A+A⊤)x

If A is symmetric (i.e. A⊤=A, which happens often in ML), this simplifies further to:

∇x​(x⊤Ax)=2Ax

Gradient of the linear term: Expanding b⊤x=b1​x1​+b2​x2​ and differentiating gives exactly b back:

∇x​(b⊤x)=[b1​b2​​]=b

Putting it together:

∇x​f=(A+A⊤)x+b=2Ax+bwhen A⊤=A

This result holds regardless of how large x is — whether it has 2 entries or a million, the gradient of x⊤Ax+b⊤x+c is always (A+A⊤)x+b.

Putting It to Work: Deriving Linear Regression from First Principles

With the gradient toolkit built, it can now be applied to a familiar model: linear regression.

Suppose the dataset has n points, each with two features, and a target (label) value:

(x11​,x12​,y1​), (x21​,x22​,y2​), …, (xn1​,xn2​,yn​)

For any data point xi​=[xi1​xi2​​], the linear regression model predicts:

y^​i​=hθ​(xi​)=θ1​xi1​+θ2​xi2​,θ=[θ1​θ2​​]

The learning goal is to choose θ so that every prediction y^​i​ is as close as possible to its true label yi​. This is captured by the mean squared error cost function:

f(θ)=n1​i=1∑n​(yi​−y^​i​)2,θ∗=θargmin​f(θ)

Step 1 — Express the error as a vector. Stack all n residuals into a single error vector:

e=⎣⎡​y1​−y^​1​y2​−y^​2​⋮yn​−y^​n​​⎦⎤​

Since ∥x∥22​=∑i=1n​xi2​, the cost function is exactly the squared 2-norm of this error vector:

f(θ)=n1​∥e∥22​

Step 2 — Separate θ from the data. Writing out each predicted value y^​i​=θ1​xi1​+θ2​xi2​, the error vector splits into a data matrix A (containing every feature) multiplied by θ, subtracted from y:

e=y−Aθ,A=⎣⎡​x11​⋮xn1​​x12​⋮xn2​​⎦⎤​

Step 3 — Expand into the quadratic form. Using ∥x∥22​=x⊤x:

f(θ)=n1​(y−Aθ)⊤(y−Aθ)=n1​(y⊤y−y⊤Aθ−θ⊤A⊤y+θ⊤A⊤Aθ)

Since y⊤Aθ and θ⊤A⊤y are both scalars and are transposes of one another, they must be equal, so the two middle terms combine:

f(θ)=n1​(θ⊤A⊤Aθ−2y⊤Aθ+y⊤y)

Step 4 — Recognize the general quadratic form. Defining B=A⊤A, b=A⊤y, and c=y⊤y:

f(θ)=n1​(θ⊤Bθ−2b⊤θ+c)

This is exactly the quadratic form worked out earlier, with B playing the role of A (and B is automatically symmetric, since (A⊤A)⊤=A⊤A).

Step 5 — Differentiate and solve. Applying the gradient rule derived above (with the symmetric-matrix shortcut):

∇θ​f(θ)=n1​(2Bθ−2b)=0Bθ=b⟹θ=B−1b

Substituting back B=A⊤A and b=A⊤y gives the celebrated normal equation of linear regression:

θ∗=(A⊤A)−1A⊤y​

This single closed-form expression gives the optimal regression coefficients directly — no iterative search required for this particular model. The overall pattern used to get here (write the loss in vector form → find its gradient → set the gradient to the zero vector → solve) is the same pattern that will reappear, in progressively more complex forms, throughout the rest of the course.
