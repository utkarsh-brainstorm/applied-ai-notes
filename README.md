# BS Applied AI & Data Science - Course Notes

Open-source archive of lecture notes, study materials, and downloadable PDFs for BS Applied AI & Data Science.

## Website Features
- Minimalist, distraction-free reading layout.
- Fast client-side navigation across semesters and subjects.
- Embedded HTML notes with mathematical typesetting and diagrams.
- One-click PDF downloads for each topic.
- Light and Dark reading modes.

## Adding Notes
To process and upload subsequent weeks of notes, run the upload script:

```bash
./upload_notes.py
```

Follow the interactive prompts to enter the week number and provide the HTML/PDF paths for each of the four Semester 4 subjects:
- Machine Learning 2 (ML2)
- Object Oriented Programming (OOP)
- Basics of Data Mining (BDM)
- Introduction to Web Technologies (ITW)

The script automatically cleans non-reader tokens, formats fonts, updates the curriculum index, and pushes changes to GitHub Pages.
