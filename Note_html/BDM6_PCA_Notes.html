1. The Story and the Data

In the previous session we saw a PCA example where the data obviously changed along the diagonal, so we could see the direction of change. Here we take a slightly different example, because the goal is to understand the physical significance of PCA: what it does, what it does not tell us, and how the trade-off is decided. Just like DFT, PCA has a trade-off, and following steps blindly without intuition leaves us unaware of the limitations.

We start with two variables:

(x1​,x2​)=(hours of study, exam score)
  • x1​ = hours of study (how much a student studied)
  • x2​ = exam score (how much they scored). The scores are normalized, so do not worry about how one can score "1 mark"; they are just relative numbers.

The data given to us is six points, each written as (x1​,x2​):

(2,1), (3,2), (4,3), (5,3), (6,5), (7,6)

Reading the first point: (2,1) means 2 hours of study and an exam score of 1.

As the hours go from 2 to 7, the score generally rises. It is not perfectly monotonic: for 4 hours and for 5 hours the score is the same (3), but the overall trend is increasing. This makes physical sense (more study, higher score), although this is certainly not true in general; it is just a convenient example.

Each data point is a 2D vector, and the question PCA answers is: in which direction does this cloud of points really vary, and can one number per student replace two?

brucks

The roadmap

  1. Data matrix X: A matrix of observations, where each row represents an observation and each column represents a feature. In this case, X is a 6×2 matrix.

  2. Mean vector mu: A vector containing the mean of each feature in the data matrix X. Here, μ is a 2×1 vector.

  3. Mean centered Xc: The data matrix X with the mean vector μ subtracted from each observation. This centers the data around the origin. Xc​=X−1μT, where 1 is a 6×1 vector of ones.

  4. Covariance matrix C: A matrix that describes the variance of each feature and the covariance between pairs of features. It's calculated as: C=N−1XcT​Xc​​, where N is the number of observations (6 in this case). C is a 2×2 matrix.

  5. Eigenvalues and eigenvectors: For the covariance matrix C, we find its eigenvalues (λ) and corresponding eigenvectors (v) by solving the equation Cv=λv.

  6. Pick PC1 = v1: The eigenvector corresponding to the largest eigenvalue is selected as the first principal component (PC1). This eigenvector represents the direction of maximum variance in the data. v1​ is a 2×1 vector.

  7. Reduce: Z1 = Xc v1: The mean-centered data Xc​ is projected onto the first principal component v1​. This reduces the dimensionality of the data. Z1​ is a 6×1 vector.

  8. Estimate: X_hat = Z1 v1^T + mu: The original data is reconstructed using the projected data Z1​, the first principal component v1​, and the mean vector μ. This is an approximation of the original data X. X^=Z1​v1T​+1μT. X^ is a 6×2 matrix.

5. Step 4: The Covariance Matrix

This step is new compared with the previous example. Earlier the data visibly varied along the diagonal (1,1), so the direction of change was obvious by eye. In general you will not be able to see the direction of change just by looking at the data, so we need a general method: compute the covariance matrix, then find its eigenvalues and eigenvectors, which give the principal components.

The covariance matrix is defined as:

C=N−11​XcT​Xc​

Here N=6, so N−1=5 (in general N can be any number of data points):

C=51​XcT​Xc​

Dimensions

  • Xc​ is 6×2 (6 rows, 2 columns)
  • XcT​ is 2×6
  • So XcT​Xc​ is (2×6)(6×2)=2×2, which has 4 numbers

The size of C depends on how many variables you started with: 2 variables give a 2×2 matrix; 5 variables would give a 5×5 matrix.

What sits inside C

C=[Var(f​1​)Cov(f​1​,f​2​)​Cov(f​1​,f​2​)Var(f​2​)​]2×2​
  • Diagonal entries: the variance of each feature vector.
  • Off-diagonal entries: the covariance between the two feature vectors (the same number appears twice, so C is symmetric).

Nothing here is a brand-new quantity: we already know variance and dot products. They simply come together in one special matrix called the covariance matrix.

The variances

We know how to compute variance: take (xi​−μ)2, sum, and divide by N−1. Since Xc​ is already centered, this is just the sum of squares of each column:

6. Step 5: Eigenvalues and Eigenvectors

You already know eigenvalues and eigenvectors, so only the use is stated here. Use the covariance matrix C to find the eigenvector v and eigenvalue λ:

Cv=λv
  • v is the eigenvector
  • λ is the eigenvalue
  • There can be more than one eigenvalue, and correspondingly that many eigenvectors.

The standard way to solve it:

det(C−λI)=0

For our C:

det[3.5−λ3.4​3.43.47−λ​]=(3.5−λ)(3.47−λ)−3.42=0

This is a quadratic equation in λ. Expanding gives λ2−(trace)λ+det(C)=0, where the trace is 3.5+3.4667=6.9667 and det(C)=3.5×3.4667−3.42=0.5733 (using unrounded entries):

λ=26.9667±6.96672−4(0.5733)​​=26.9667±46.24​​=26.9667±6.80​λ1​≈6.88,λ2​≈0.083​

There are two eigenvalues because the covariance matrix is 2×2, and each eigenvalue has a corresponding eigenvector (found in Step 6). Before computing the eigenvectors, let us understand what these two numbers mean.

7. What Do the Eigenvalues Mean Physically

Eigenvalues of the covariance matrix represent the amount of variance in each direction.

Recall that PCA is about direction: we want the direction in which the data is varying. Now we can be more specific:

  • The eigenvalues tell us how much the data varies in a particular direction.
  • The eigenvectors (found next) tell us which direction that is. The first eigenvector is the direction of maximum variance; along the second eigenvector the data varies a bit less, and so on.

Variance is essentially change, and change is what we care about: it is the change that distinguishes student A from student B.

Total variation

Since λ1​ and λ2​ are the variances along two different directions (two directions because there are two variables), the total variation in the data is:

Total variation=λ1​+λ2​=6.88+0.083≈6.966

This number does not have a clear physical meaning on its own, but it is useful for comparison: given two or more datasets, you can tell which one varies more and which one varies less.

Note for Review: Total variation equals the trace of C (sum of diagonal entries): 3.5+3.47=6.97. Rotating the axes to the eigen-directions does not create or destroy variance; it only redistributes it, piling it almost entirely onto the first direction.

Percentage of variance explained

Name the directions PC1 and PC2 (principal component 1 and 2), the directions of λ1​ and λ2​ respectively.

Variance explained by PC1=λ1​+λ2​λ1​​×100=6.9666.88​×100≈98.8%Variance explained by PC2=λ1​+λ2​λ2​​×100=6.9660.083​×100≈1.2%

^fg3^

^/fg3^

^tg3^

So the direction that corresponds to λ1​ (PC1) carries 98.8% of all the variation in the data, which is almost everything, and nearly nothing is left for the second direction. Out of the data we have found one direction that holds almost all the change.

With more variables, the variance spreads over more components but always in decreasing order. For example, the first component might hold 90%, the second 7.9%, the third 2.1%. The first principal component always corresponds to the largest eigenvalue and always captures the most variation in the data. That is how principal components work.

8. Step 6: Finding the Direction of Variance

The eigenvalues told us how much variance exists (6.88 along one direction and 0.083 along the other). Now we want the actual directions, and those are the eigenvectors.

Use the same equation:

Cv1​=λ1​v1​=6.88v1​

To solve for v1​=(a,b)T, rewrite as (C−6.88I)v1​=0:

[3.5−6.883.4​3.43.47−6.88​][ab​]=[−3.383.4​3.4−3.41​][ab​]=[00​]

The first row gives −3.38a+3.4b=0, so b≈0.994a≈a. The direction is therefore (1,1). Normalizing to unit length (divide by 12+12​=2​):

v1​≈[0.7070.707​]=2​1​[11​]=PC1

Likewise for the second eigenvalue λ2​=0.083 (the same process gives 3.42a+3.4b=0, so b≈−a):

v2​=2​1​[−11​]=PC2

Check of perpendicularity: v1​⋅v2​=21​[(1)(−1)+(1)(1)]=0, so v1​⊥v2​.

Eigenvectors of a covariance matrix are always perpendicular to each other. With three eigenvectors, v1​⊥v2​, v1​⊥v3​ and v2​⊥v3​. This is a property that holds by definition.

Interpreting the result

  • v1​ (PC1) is the eigenvector corresponding to λ1​, the direction of maximum variance. Along it lies 98.8% of the variation.
  • v2​ (PC2) is the direction holding the remaining variation (1.2%).

This is the same vector we established in the previous example, where we just looked at the data and saw that it varied along the diagonal. The new thing is that we did not visualize anything. We only used the data: mean-centered it, built the covariance matrix, did the eigenvalue and eigenvector analysis, and the direction fell out.

The data lies somewhere in 2D space and varies in a certain direction that, just by looking, may be hidden. PCA's job is to bring that hidden dimension out through this process:

We have now reached the actual data reduction. All the previous steps (centering, covariance, eigenvalues, eigenvectors) were preparation.

Z1​=Xc​v1​

10. Step 8: Data Estimation

The final step is the reverse of the previous one. The numbers in Z1​ (some negative, some positive) are just internal working: what we ultimately want is our original data. So we need to get X back from Z1​. This is data estimation (reconstruction).

X^=Xc​v1​v1T​+μ​=Z1​v1T​+μ​
  • Xc​v1​ is just Z1​.
  • v1T​ is the transpose of the two-dimensional vector v1​, i.e. [0.707, 0.707]. Shape check: Z1​ is 6×1, v1T​ is 1×2, so Z1​v1T​ is 6×2 again.
  • μ​ is added back, because we subtracted the mean during mean centering. To get the data back, we must add it back.

Note for Review: Look at the error pattern. Five points are off by a nearly identical tiny shift, while the point (5,3) takes most of the error. That is the point that sits off the diagonal, the same one that breaks the "score keeps rising" pattern (the score stays at 3 for both 4 and 5 hours). PCA with one component forces every point onto the PC1 line, so whatever lies away from that line (the PC2 part of the data) is what gets erased. The total squared error is ∑∥x−x^∥2≈0.417, which equals (N−1)λ2​=5×0.083. The discarded eigenvalue is literally the price you pay.

How to reduce the error

If we wanted to be more accurate, the only option is to take the second eigenvector v2​ as well, i.e. project onto v2​ too, and then we would get the entire data back exactly. But that makes no sense, because we would have the same number of values before and after the reduction. In practice, for large datasets small errors of 2%, 5% or 10% often do not matter. The moment you admit some inaccuracy or approximation, PCA and DFT come into the picture.

11. Lossy Methods and the Trade-Off

Both PCA and DFT are lossy methods for data reduction. "Lossy" means some information is lost, and that is where the trade-off comes from.

  • Be careful about where you apply them. For example, with medical data you had better not lose information, so you should not apply this kind of reduction there.
  • If you are comfortable with a trade-off, you can use these methods.

There are several such methods:

Method Full name Remark
PCA Principal Component Analysis Very popular and interesting; eigenvalue and eigenvector based
DFT Discrete Fourier Transform Complex exponential based
DWT Discrete Wavelet Transform Slightly better than DFT, but quite mathematical and it deviates from the main topic of data mining; it is mentioned in the textbook but not covered in depth here
DCT Discrete Cosine Transform Another member of the family

PCA and DFT are used here as examples of lossy data-reduction methods. The key message is not the list of names but that you must be careful about when you apply them.

12. PCA versus DFT

The two methods operate in very different ways, yet at a closer look share a lot.

Different on the surface

PCA DFT
Mathematical machinery Eigenvector / eigenvalue based Complex exponentials
Basis functions Eigenvectors, derived from the data itself (from the eigen-decomposition of the covariance matrix) Complex exponentials, ei2πnk/N, fixed in advance
What is measured Change / variation (an eigenvalue is the change along one direction) Frequency

Same underneath

  • PCA is about change or variation (the direction of change).
  • DFT is about frequency, and frequency is simply the rate of change. For example, a 2Hz sine means 2 cycles per second, and a 20Hz sine means 20 cycles per second.

So even though they come from different principles, both exploit the same underlying property: change. One does it through eigenvalues along directions, the other through complex basis functions and the idea of frequency.

How each one reduces data

PCA DFT
What you rank by Eigenvalues λ1​≥λ2​≥λ3​… (variance) Magnitude of coefficients (energy)
What you keep Only the first (few) eigenvectors, e.g. only λ1​ and v1​ (PC1) Only the highest-energy coefficients, e.g. X(0),X(1)
What you discard The remaining eigenvalues and eigenvectors The low-energy coefficients

In both cases you choose directions or coefficients based on energy, magnitude or variance, which in PCA is λ. You take the first few and discard the rest. In our example we kept only λ1​ and v1​; in DFT we kept only X(0) and X(1), because the other energies were relatively small.

Note for Review: Exams like the question "how are PCA and DFT different and how are they similar?" Differ in basis (data-derived eigenvectors vs fixed complex exponentials). Similar in philosophy (rank components by variance or energy, keep the biggest, accept loss). The basis functions also have interesting mathematical properties beyond physical significance, but these are outside the scope of this course.

13. Should You Reduce Data at All

Data reduction is useful for storage, for efficiency, and for general-purpose analysis (when you simply want to look at the data in a simpler form). PCA and DFT are two such tools, and DWT and DCT are others.

But it cannot be a blind choice of "I need to reduce my data, so I'll apply PCA" or "somebody applies DFT". You must:

  1. First decide whether data reduction is necessary or beneficial for your data, and in what form.
  2. Understand the implications of reducing it (what you lose, and whether you can afford to lose it).
  3. Only then choose a tool such as PCA or DFT.

In other words, establish the context first. The tools can wait.

Work these out on paper. They are designed to make you use the ideas, not recite them.

1. Units matter. Suppose the exam scores in the dataset were recorded out of 100 instead of being normalized (every x2​ value multiplied by 100), while hours stay the same. Without doing the full eigen-decomposition, predict what happens to the covariance matrix, to which variable dominates PC1, and to the "percentage of variance explained by PC1". What does this tell you about why we never mix hours and marks naively, and what would you do to the data before PCA to avoid the problem?

2. Choosing how many components. A dataset of 1000 students has 4 variables, and its covariance matrix has eigenvalues 9, 3, 1.5, 0.5. (a) What percentage of the variance does each component explain? (b) How many components must you keep to retain at least 90%? (c) How many numbers do you store before and after reduction, ignoring μ​ and the eigenvectors? (d) Why does the second answer not depend on the number of students?

3. Where does the error go? In the lecture example, project each centered data point onto v2​=2​1​(−1,1) to get Z2​=Xc​v2​. Which point has the unusually large value, and how does this connect to the large reconstruction error you saw for that same point? Then verify that N−11​∑z2,i2​ equals λ2​, and explain in a sentence why this must be true.

4. The hospital proposal. A hospital data team proposes applying PCA to patient vital-sign records, keeping enough components to retain 98% of the variance, to cut storage costs by 60%. Argue for and against the proposal. What would you want to know about the data and its use before deciding, and what could be hiding inside the discarded 2%?

5. Same total, different story. Dataset A has eigenvalues (6.9, 0.1) and dataset B has eigenvalues (3.6, 3.4). Both have total variation 7.0. (a) Which dataset compresses better with one component, and why? (b) What would the off-diagonal covariance entry look like for each (large or near zero)? (c) Make the parallel to DFT: what kind of signal would compress well with just X(0),X(1), and what kind of signal would not?
